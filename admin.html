Preferencias de reserva

Si se desactiva, solo podrán continuar las clientas cuyo teléfono o email ya esté registrado. A las nuevas se les mostrará un aviso para contactar directamente con Sabina.

La agenda mostrará horarios con este intervalo. También ofrecerá el inicio justo al terminar una cita existente cuando sea necesario para aprovechar el tiempo. Se ocultarán opciones que dejen huecos pequeños inferiores al intervalo elegido entre citas.

IMPORTANTE: esta entrega es una maqueta funcional local. Los datos se guardan en el navegador mediante localStorage y no se sincronizan entre dispositivos ni constituyen reservas online reales. Antes de publicarla para clientes hay que conectar autenticación segura, base de datos y validación de disponibilidad en servidor.
